# Shop

A web page calls the shop's API, and the gateway stands in front of that API.

## 1. Open the shop

Open the Shop tab. The page lists three products.

## 2. Call the API

Call the API through the gateway.

```bash
curl "http://localhost:8082/shop/products"
```

[Try it](action:try-it)

## 3. Look at the traffic

Open the API in the console, then its API Traffic.
